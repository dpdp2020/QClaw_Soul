# 量化策略模拟回测

> 策略靠不靠谱？用历史数据回测验证你的交易策略

## 前置依赖

```bash
pip install pandas openpyxl
```

## 核心能力

### 能力1：让我描述策略逻辑（均线/MACD/RSI 等）

用 `execute_command` 运行Python回测脚本（pandas+numpy），计算策略收益、最大回撤、夏普比率等指标。

### 能力2：获取历史行情数据（web_search/execute_command）

用 `execute_command` 运行Python回测脚本（pandas+numpy），计算策略收益、最大回撤、夏普比率等指标。

### 能力3：编写回测脚本（execute_command + Python）

用 `execute_command` 运行Python回测脚本（pandas+numpy），计算策略收益、最大回撤、夏普比率等指标。

### 能力4：计算绩效指标（年化收益/最大回撤/夏普比率）

运行脚本进行数据分析处理。

### 能力5：生成回测报告

用 `write_to_file` 生成文件。

## 使用流程

### 步骤 1：收集用户需求

向用户确认以下信息（如果未主动提供）：
- 策略描述（均线交叉/RSI/布林带/自定义）
- 回测标的（股票代码/指数）
- 回测时间范围
- 初始资金和交易成本设定

### 步骤 2：检索外部信息

执行以下搜索获取真实数据：

```
web_search("[策略名] 量化回测 Python")
web_search("[标的] 历史数据 下载")
```

确保获取到以下资源：
- 历史行情数据
- 策略模板

### 步骤 3：运行脚本处理数据

```bash
python3 scripts/quant_backtester_tool.py run \
  --input "用户提供的输入" \
  --output "/path/to/output_file"
```

读取脚本输出的结果，确认数据处理成功。

### 步骤 4：生成最终产出

基于脚本输出和搜索到的资源，用 `write_to_file` 生成以下文件：

- **回测报告（Markdown）**
- **绩效数据表**

输出格式要求：Markdown 回测报告 + 绩效指标表

### 步骤 5：汇总交付

向用户展示：
1. 生成的文件路径和内容摘要
2. 搜集到的资源链接列表
3. 关键发现和建议

## 注意事项

- 所有数据必须来自 `web_search` / `web_fetch` 的真实搜索结果，**严禁编造数据**
- 数据缺失时标注"数据不可用"而非猜测
- 报告必须保存为文件（`write_to_file`），不能只在对话中输出
- 建议结合人工判断使用，AI 分析仅供参考
